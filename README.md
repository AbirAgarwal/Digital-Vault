# Personal Digital Vault

A secure local vault to store service credentials with master password protection, built with Python and Tkinter.

## Features
- Master password login (set on first use)
- Add, view, edit, and delete entries (service, username, password, notes)
- Copy password to clipboard
- Search functionality
- Data saved locally to JSON

## ⚠️ Security Note
This is a learning project. Passwords are stored in plain text in a local JSON file — **not** suitable for production use or storing real sensitive credentials.

## How to Run
```bash
python DigiVault.py
```

## Requirements
- Python 3.x
- Tkinter (usually included with Python)

## Built With
- Python + Tkinter
